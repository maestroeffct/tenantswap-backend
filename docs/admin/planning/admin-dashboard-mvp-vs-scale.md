# Admin Dashboard MVP vs Scale Plan

Audience: founder, product, engineering

## MVP Admin Dashboard
Goal: operate the platform safely after launch with a small admin team.

### MVP Scope
- Overview metrics
- User search/detail
- Listing search/detail
- Matching/interests/chains intervention tools
- Billing visibility and manual overrides
- Reliability penalties / unblock tools
- Notification failure visibility
- Audit logs

### MVP Outcomes
- resolve user issues quickly
- inspect business-critical records
- manually intervene when automation fails
- keep actions auditable

## Scale Dashboard
Goal: operate efficiently with high volume and minimal manual review.

### Scale Additions
- support ticketing
- moderation queues
- anomaly/risk detection
- queue health dashboards
- webhook failure center
- regional analytics
- export/report system
- role-specialized admin views
- incident management
- bulk actions

## Team-Oriented Views
### Founder / Ops Lead
Needs:
- overview
- revenue
- growth
- risk alerts
- system health

### Support Team
Needs:
- user search
- listing detail
- request/chain detail
- manual corrections

### Billing Team
Needs:
- transactions
- subscription state
- webhook failures
- override tools

### Trust & Safety Team
Needs:
- reported users/listings
- no-show offenders
- fraud signals
- penalty tools

### Engineering / Ops
Needs:
- queue health
- job failures
- integration failures
- incident controls

## Rollout Sequence
### Stage 1
- admin auth + roles
- overview
- users
- listings
- audit log

### Stage 2
- interests/chains
- billing
- notifications delivery issues
- reliability controls

### Stage 3
- support queue
- moderation queue
- incidents
- analytics
- exports

## Success Metrics
- admin time-to-resolution
- percentage of issues resolved without DB manual intervention
- notification failure detection time
- payment issue resolution time
- fraud/no-show intervention effectiveness
- operational dashboard adoption by team role
